# SansAlpha

## 題目描述 (Description)

The Multiverse is within your grasp! Unfortunately, the server that contains the secrets of the multiverse is in a universe where keyboards only have numbers and (most) symbols.

### 提示 (Hints)

1. Hint 1  
    Where can you get some letters?

## 解題思路 (Solution Walkthrough)

1. **第一步**：先隨便試 `./*/*`，結果發現 flag 的路徑，目前就是要想辦法讀取他

    ```text
    SansAlpha$ ./*/*
    bash: ./blargh/flag.txt: Permission denied
    ```

2. **第二步**：接下來就照它的順序猜 flag 的完整路徑在哪裡

    ```text
    SansAlpha$ /????
    bash: /boot: Is a directory

    SansAlpha$ /????/??
    bash: /proc/18: Is a directory

    SansAlpha$ /????/???
    bash: /proc/bus: Is a directory

    ...

    SansAlpha$ /????/??????????
    bash: /home/ctf-player: Is a directory

    SansAlpha$ /????/??????????/??????/????
    bash: /????/??????????/??????/????: No such file or directory

    SansAlpha$ /????/??????????/??????/????.???
    bash: /home/ctf-player/blargh/flag.txt: Permission denied
    ```

3. **第三步**：接下來就不會了，看別人的解法他是用 `/bin/base64` 來取得 flag，需輸入 `/???/???[!_]64 /????/??????????/??????/????.???`，`[!_]` 是為了不要讓他 match 到 x86_64
